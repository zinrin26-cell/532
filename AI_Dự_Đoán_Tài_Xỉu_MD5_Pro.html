Hướng Dẫn Đưa Tool & API Lên Web Miễn Phí

BƯỚC 1: Đưa Backend API Node.js (lcapi.js) Lên Cloud (Render.com)

  1. Tạo file package.json với lệnh: npm init -y và cài axios/express: npm i express axios cors.
  2. Trong lcapi.js, hãy thêm const cors = require('cors'); app.use(cors()); và dùng process.env.PORT || 3009.
  3. Đẩy code lên GitHub cá nhân của bạn.
  4. Đăng ký tài khoản miễn phí tại Render.com, chọn New Web Service, kết nối repository GitHub vừa tạo.
  5. Sau khi deploy xong, Render sẽ cấp cho bạn Link API live (VD: https://my-tx-api.onrender.com/api/lcmd5).

BƯỚC 2: Đưa Giao Diện HTML Lên Web Tĩnh (Netlify / Vercel / GitHub Pages)

  1. Lưu code HTML này thành file index.html.
  2. Truy cập Netlify Drop.
  3. Kéo thả thư mục chứa file index.html vào Netlify Drop. Bạn sẽ có ngay trang Web công khai hoàn toàn miễn phí trong 10 giây!

BƯỚC 3: Kết Nối Tool Web Với Backend Live

Trên Web Tool vừa tạo, mở Nút Bánh Răng Cài Đặt (Top Right), dán Link API từ Render vào ô URL API và bấm Lưu Cấu Hình!
